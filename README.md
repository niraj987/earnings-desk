# 📊 Earnings Desk — End-to-End Full-Stack Financial Intelligence

An end-to-end full-stack financial earnings analysis platform powered by **React**, **Express**, **Node.js**, **SQLite**, and a **LangGraph Multi-Agent Engine** (Extraction · Revenue Analyst · Risk Analyst · Outlook Analyst · Comparison Agent · Editor Manager).

Every claim generated by the specialist agents traces directly to an extracted figure with **100% provenance verification**.

## 🚀 Quick Start

### 1. Run the Full-Stack Application
To start the Express server (which serves both the REST API and the built React frontend on port 5000):


Open your browser to:

To run with active hot-reloading for both backend and frontend concurrently:

* React Frontend (Vite): `http://localhost:3000`

## 💾 SQLite Database Schema

The application uses an embedded SQLite database (`server/earnings_desk.db`) powered by Node's native C++ SQLite engine (`node:sqlite`).

* **`reports`**: Stores company name, period (e.g. Q3 FY2026), full current report text, and optional prior quarter report text.
* **`analyses`**: Stores the generated markdown note, overall verdict (Positive / Balanced / High Risk), coverage % (100%), disagreements list, trace log, and timestamp.
* **`figures`**: Stores all extracted financial figures (`F1`, `P1`, etc.) with key, label, value, unit, display formatting, and source sentence.
* **`agent_views`**: Stores the output of each specialist agent (Revenue, Risk, Outlook, Comparison) including stance, score, headline, claims, and derived metrics.
* **`scenarios`**: Stores user-created **What-If simulation scenarios** with tweaked figures and recalculated stances.
* **`qa_history`**: Stores natural-language queries and grounded answers generated during Q&A sessions.

## 🌟 Interactive Features

1. **📝 Analyst Note Tab**: Formatted one-page executive report with stance badge, summary, revenue highlights, risk flags, guidance, and QoQ table. Hover or click on any reference pill (e.g., `[F1]`, `[K1]`, `[S10]`) to view its underlying formula, extracted value, and source sentence.
2. **🕸 Multi-Agent Workflow Tab**: Visual interactive flowchart of the Fan-Out / Fan-In coordination pattern, with live per-agent execution times and execution trace logs.
3. **🔢 Figures & What-If Simulator**: Interactive table allowing you to tweak any figure (e.g., cut Q4 guidance to $4,600M, raise debt to $5,000M) and recalculate the multi-agent analysis in real time. Scenarios are saved directly to SQLite.
4. **🧑‍💼 Specialist Agent Views**: Expandable inspector cards for the Revenue Analyst, Risk Analyst, Outlook Analyst, and Comparison Agent.
5. **🔍 Claim Tracer Tab**: Grounding auditor that maps any sentence in the note to the exact numbers and verbatim quotes that substantiate it.
6. **💬 Grounded Q&A Assistant ("Ask the Desk")**: Query the report in natural language and receive instant, zero-hallucination answers backed by evidence IDs.
7. **🗄️ Database Management Modal**: Browse all stored earnings reports and what-if scenarios in SQLite, switch between reports, or delete records.
